# Matthew Macalintal — Portfolio

Personal portfolio site. Trilingual (English / Spanish / Filipino), hand-written HTML, CSS and
JavaScript — no frameworks, no build step.

**Live:** https://hitori-kaizen.github.io

## Structure

| Path | What it is |
|------|-----------|
| `index.html` | Language splash — entry point |
| `english/Main.html` | Full single-page site (English) |
| `spanish/Main-es.html` | Full single-page site (Spanish) |
| `filipino/Main-fil.html` | Full single-page site (Filipino) |
| `css/style.css` | All styles |
| `js/main.js` | Cursor, menu, scroll spy, local clock |
| `js/fx.js` | Command palette (Ctrl+K), CRT mode, matrix rain, scroll engine, darkroom physics |
| `js/validation.js` | Contact form validation |
| `files/` | CV and downloadable project sources |
| `motion-check.html` | Diagnostic for `prefers-reduced-motion` |

## Notes

- Press <kbd>Ctrl</kbd>+<kbd>K</kbd> for the command palette.
- Respects `prefers-reduced-motion`; append `?motion=full` to force animation.
- Built in Madrid.
